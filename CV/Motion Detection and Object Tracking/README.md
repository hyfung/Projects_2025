## Object Tracking

Needs tracking to recognize object detected in frames

Three main steps in the cycle

1. Assign detection to tracks
2. Update tracks
3. Predict tracks

And two concepts

- Detections
    - Bounding boxes
    - Centroids
    - Assignment status
- Tracks
    - Identifier
    - Number of frames

Even if object disappears, you expect to see it again in future in new position
