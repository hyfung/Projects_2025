## Generative AI Architecture and Models

| Model           | Training                 |
| --------------- | ------------------------ |
| RNN             | Loop-based design        |
| Transformers    | Self-attention mechanism |
| GAN             | Competitive approach     |
| VAE             | Characteristics-based    |
| Diffusion model | Statistical properties   |

- RNN
  - Sequential or time series
    - Natural order
    - Time based dependencies
  - Loop based design
  - Fine-tuning pretrained model to specific dataset
  - Fine-tuning RNN adjusts weights
  - Application
    - NLP
    - Translation
    - Speech recognition
    - Image captioning
- Transformer
  - Input layer > Hidden layer > Output layer
  - Self attention mechanism: Focus on most important parts
  - Parallelization for efficient training
  - Fine-tuning trains only output layer
  - Example: GPT, generates text based on input pattern, mirrors training data
- GAN
  - Adversarial process
  - Generator
    - Creates fake sample
  - Discriminator
    - Determines fake or real
  - Video and image generation
- VAE
  - Encoder decoder framework
  - Encoder compress input data
  - Decoder recreates original data
  - Captures pattern in input data
  - Use probability distribution to generate output
- Diffusion Models
  - Probabilistic generative model
  - Remove noise
  - Reconstructing distorted data
  - Statistical properties

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

# Selecting the model. You will be using "facebook/blenderbot-400M-distill" in this example.
model_name = "facebook/blenderbot-400M-distill"

# Load the model and tokenizer
model = AutoModelForSeq2SeqLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

# Define the chat function
def chat_with_bot():
    while True:
        # Get user input
        input_text = input("You: ")

        # Exit conditions
        if input_text.lower() in ["quit", "exit", "bye"]:
            print("Chatbot: Goodbye!")
            break

        # Tokenize input and generate response
        inputs = tokenizer.encode(input_text, return_tensors="pt")
        outputs = model.generate(inputs, max_new_tokens=150)
        response = tokenizer.decode(outputs[0], skip_special_tokens=True).strip()

        # Display bot's response
        print("Chatbot:", response)

# Start chatting
chat_with_bot()
```
