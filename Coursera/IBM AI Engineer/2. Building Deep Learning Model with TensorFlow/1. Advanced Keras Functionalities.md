## Advanced Keras Functional API

### Introduction to Advanced Keras

- Sequential API
  - Simple linear stack of layers
- Functional API
  - More flexibility and control
  - Intricate models
    - Multiple inputs and outputs
    - Shared layers
    - Non-sequential data flows
- Subclassing API
  - Custom Model

> `tf.GradientTape()` provides more flexibility and control over `Keras.fit()`

#### Sequential API Sample

> Layers are added in a linear stack

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

model = Sequential([
    Dense(64, activation='relu', input_shape=(784, )),
    Dense(10, activation='softmax')
])

model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
```

#### Functional API Sample

> Flexibility: Complex architecture like multibranch models

> Clarity: Explicit model structure

> Reusability: Layers and models can be reused across different arts of architecture

```python
from tensorflow.keras.models import Model
from tensorflow.keras.layers import Input, Dense

inputs = Input(shape=(784,))

x = Dense(64, activation='relu')(inputs)
outputs = Dense(10, activation='softmax')(x)

model = Model(inputs=inputs, outputs=outputs)

model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
```

```python
from tensorflow.keras.layers import concatenate

inputA = Input(shape=(64,))
inputB = Input(shape=(128,))

x = Dense(8, activation='relu')(inputA)
x = Dense(4, activation='relu')(x)

y = Dense(16, activation='relu')(inputB)
y = Dense(4, activation='relu')(y)

combined = concatenate([x, y])

z = Dense(2, activation='relu')(combined)
z = Dense(1, activation='linear')(z)

model = Model(inputs=[inputA, inputB], outputs=z)

model.compile(optimizer='adam', loss='mean_squared_error')
```

```python
from tensorflow.keras.models import Model
from tensorflow.keras.layers import Input, Dense

inputs = Input(shape=(784,))

x = Dense(64, activation='relu')(inputs)

outputs = Dense(10, activation='softmax')(x)

model = Model(inputs=inputs, outputs=outputs)
```

> Practical example implementing a complex model

```python
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, concatenate
from tensorflow.keras.activation import relu, linear

inputA = Input(shape=(32, 32,1 ))
x = Conv2D(32, (3, 3), activation=relu)(inputA)
x = MaxPooling2D((2, 2))(x)
x = Flatten()(x)

inputB = Input(shape=(32, 32, 1))
y = Conv2D(32, (3, 3), activation=relu)(inputB)
y = MaxPooling2D((2, 2))(y)
y = Flatten()(y)
y = Model(inputs=inputB, outputs=y)

combined = concatenate([x.output, y.output])

z = Dense(64, activation=relu)(combined)
z = Dense(1, activation=linear)(z)

model = Model(inputs=[x.input, y.input], outputs=z)
```

##### Keras Subclassing API

> Build your own model

- Flexibility
- Custom and dynamic model
- Custom training loops
- Research and prototyping

```python
import tensorflow as tf

class MyModel(tf.keras.Model):
  def __init__(self):
    super(MyModel, self).__init__()
    self.dense1 = tf.keras.layers.Dense(64, activation='relu')
    self.dense2 = tf.keras.layers.Dense(10, activation='softmax')
  def call(self, inputs):
    x = self.dense1(inputs)
    return self.dense2(x)

model = MyModel()
loss_fn = tf.keras.losses.SparseCategoricalCrossentropy()
optimizer = tf.keras.optimizer.Adam()
```
