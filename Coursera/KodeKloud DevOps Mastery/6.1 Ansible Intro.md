## Ansible Inventory

> A file to list a set of hosts in the system

YAML Format
```yaml
all:
  hosts:
    web1.example.com:
      ansible_host: 192.168.1.10
      ansible_user: admin
      ansible_ssh_private_key_file: /path/to/ssh_key
    db1.example.com:
      ansible_host: 192.168.1.11
      ansible_user: dbadmin
      ansible_ssh_private_key_file: /path/to/another_key
```

INI Format
```ini
[vms]
target1 ansible_host=192.168.0.1 ansible_ssh=pass

[web_servers]
web1.example.com ansible_ssh_private_key_file=/path/to/ssh_key
web2.example.com ansible_ssh_private_key_file=/path/to/ssh_key

[database_servers]
db1.example.com ansible_ssh_private_key_file=/path/to/another_key

[all:vars]
ansible_user=admin
ansible_ssh_private_key_file=~/.ssh/id_rsa
```

> Group resources with `[<name>]`

## Playbook & YAML
- `ansible-playbook -i inventory_file -l web_servers playbook.yml`
    - where `-l web_servers` only runs ansible on resource in group `web_servers`
