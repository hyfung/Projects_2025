# 7.2

## HCL Basics

### Syntax

| Keyword      | Function                        | Example                    |
| ------------ | ------------------------------- | -------------------------- |
| `block`      | Block name defines the platform | `resource`                 |
| `parameters` | Resource type and name          | `"local_file"` `"my_file"` |
| `key=value`  | Arguments                       | `host = "192.168.0.01"`    |
|              |                                 |                            |

```
<block> <parameters> {
    key1 = value1
    key2 = value2
}
```

```
resource "local_file" "pet" {
    filename = "/root/file.txt"
    content = "blah"
}
```
