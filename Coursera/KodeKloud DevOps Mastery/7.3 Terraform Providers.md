# 7.3

## Configuration Directory

- Terraform looks for `*.tf` files
- You can use single configuration file like `main.tf`

| Name           | Purpose                                  |
| -------------- | ---------------------------------------- |
| `main.tf`      | Main file containing resource definition |
| `variables.tf` | Variable declaration                     |
| `outputs.tf`   | Output from resources                    |
| `provider.tf`  | Provider definition                      |

## Managing Multiple Providers

- You can use multiple provider within same Terraform file

## Input Variables

`variables.tf`

```
variable "myvar" {
    default = "test"
}
```

`main.tf`

```
resource "local_file" "pet" {
    filename = var.filename
    content = var.content
}
```

## Variable Block

> Boolean

```
variable my_bool {
    type = bool
    default = true
}
```

> String

```
variable my_string {
    type = string
    default = "foo"
}
```

> Number

```
variable my_num {
    type = number
    default = 0
}
```

> List

```
variable my_list {
    type = list
    default = [0, 1, 2]
}
```

> Map

```
variable my_map {
    type = map
    default = {
        "k1" = "v1"
    }
}
```

> Set

```
variable my_set {
    type = set(TYPE)
    default = ["."]
}
```

> Tuple

```
variable my_tuple {
    type = tuple([string, number, bool])
    default = ["Hi", 7, true]
}
```

> Object

```
variable my_object {
    type = object({
        name = string
        age = number
    })
}
```

## Exploring Variables

- Empty variable will be asked if left empty
- `-var "name=value"`
- `export TF_VAR_name=`

Automatically loads the following variable files

- `terraform.tfvars`
- `terraform.tfvars.json`
- `*.auto.tfvars`
- `*.auto.tfvars.json`

Variable Definition Precedence, Highest to Lowest

- `-var` or `-var-file`
- `*auto.tfvars`
- `terraform.tfvars`
- Environment variables
