# 5.4

## Types Of Networking

- Container-to-container
- Pod-to-pod
- Pod-to-service
- External-to-service

## Key Principles

- IP address is assigned to a pod
- No NAT between Pods
  - All pods are part of flat network
- Every Pod has its own IP
  - K8s assigns an IP to each pod
- Kube-proxy for Service IP
  - iptables or IPVS to route traffic to service endpoints

## Single Node Internal Networking

- Private network is created
- Pod is assigned an internal IP
- Multiple pod gets multiple pod

## Cluster Networking

- Does not automatically setup networking
- Expect users to setup networking
- Use Container Network Interface (CNI) as plugin
