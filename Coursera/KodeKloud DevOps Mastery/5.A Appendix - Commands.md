# Kubernetes Command Quick Reference

## Cluster and Context Management

`kubectl config get-contexts`

`kubectl config use-context <context-name>`

`kubectl config current-context`

## Basic Info and Nodes

`kubectl cluster-info`

`kubectl get nodes`

`kubectl describe node <node-name>`

## Pods Management

`kubectl get pods`

`kubectl get pods --all-namespaces`

`kubectl create -f pod.yaml`

`kubectl delete pod <pod-name>`

`kubectl logs -f <pod-name>`

`kubectl exec -it <pod-name> -- <command>`

## Services and Deployments

`kubectl get svc`

`kubectl describe svc <service-name>`

`kubectl get deployments`

`kubectl scale deployment <deployment-name> --replicas=<count>`

`kubectl apply -f deployment.yaml`

`kubectl delete deployment <deployment-name>`

## ConfigMaps and Secrets

`kubectl create -f configmap.yaml`

`kubectl get configmaps`

`kubectl create -f secret.yaml`

`kubectl get sercets`

## Namespaces

`kubectl get namespaces`

`kubectl create namespace <namespace-name>`

`kubectl delete namespace <namespace-name>`

## Persist Volume and Claims

`kubectl get pv`

`kubectl get pvc`

## Resource Status and Descriptions

`kubectl describe <resource-type> <resource-name>`

`kubectl rollout status deployment/<deployment-name>`

`kubectl get events`

## Port Forwarding and Accessing Applications

`kubectl port-forward pod/<pod-name> <local-port>:<remote-port>`

`kubectl port-forward svc/<service-name> <local-port>:<remote-port>`

## Editing and Debugging Resources

`kubectl edit <resource-type> <resource-name>`

`kubectl debug -it <pod-name> --image=<debug-image>`

## Delete Resources

`kubectl delete <resource-type> <resource-name>`

`kubectl delete pods --all -n <namespace-name>`
