# Docker

## Docker Engine

- Maps the child system PID to host system PID
- Separate by namespaces
- How much the resources allocated is not limited by default
  - cgroup or control group to limit resource allocated
  - `--cpus=0.5`
  - `--memory=100m`

## Docker Storage

- Layered architecture
- `/var/lib/docker`

  - `containers`
  - `image`
  - `volumes`

- Shared storage

  - Volume mount: Docker volume
  - Bind mount: Local folder

- Storage Drivers
  - AUFS
  - ZFS
  - BTRFS
  - Device Mapper
  - Overlay
  - Overlay2

## Docker Network

Types of network

- Bridge
  - Private internal network on the host
  - Internal IP address
  - Container can access each other
  - Expose of port needed
- Host `--network=host`
  - No network isolation
  - Automatically exposed same port on host
- None `--network=none`
  - Not attached to any network at all
  - Isolated network

User-defined Network

- `docker network create --driver bridge --subnet 182.18.0.0/16 NAME`
- `docker network ls`
- `docker inspect NAME` to check networks
- Attach to container
- Docker containers can reach each other by Embedded DNS via container name
