- Code packaging
- Clone repo and package
- Unit test
- Integration test
- Security checks

## Key pieces of CD
- Deploy the code to system
- Server, container, bare metal, on prem

## Deployment versus Delivery
- In Delivery, someone press the deployment button
- Delivery: Deploy the code manually
- Deployment: Code is automatically deployed after CI

# Jenkins Pipeline (Jenkinsfile)

## What is a Jenkinsfile
- Within stages you can have multiple stage
- `stage('dev')` vs `stage('uat')`
- In a stage you have steps

## Building a Jenkinsfile
- Named `Jenkinsfile`
- `agent` is a build agent
- Single stage, multi stage
    - Stage: `dev`, `uat`, `prod`
    - Stage involves some steps
- Steps are executed by Jenkins
    - `git`
    - `echo`
