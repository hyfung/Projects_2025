### Service
- Service

    - Node Port (Fixed port on each node)
    - Load Balancer (Externally with cloud load balancer)
    - External Name (Maps to DNS)

- Host Port

#### ClusterIP
- Exposes deployment only inside cluster
- Default service type
- Internal communication

```bash
kubectl expose deployment <deployment-name> --type=ClusterIP --port=<port> --target-port=<container-port>
```

#### Node Port
- Each node's IP at static port
- Accessed externally

```bash
kubectl expose deployment <deployment-name> --type=NodePort --port=<port> --target-port=<container-port>
```

#### Load Balancer
- Provisions an external load balancer
- Exposes the deployment

```bash
kubectl expose deployment <deployment-name> --type=LoadBalancer --port=<port> --target-port=<container-port>
```

#### External Name
```bash
kubectl create service externalname <service-name> --external-name=<external-domain>
```

### Ingress
- Expose HTTP and HTTPS routes

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: example-ingress
spec:
  rules:
  - host: example.com
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: my-service
            port:
              number: 80
```

```bash
kubectl apply -f ingress.yaml
```

### Port Forwarding
```bash
kubectl port-forward deployment/<deployment-name> <local-port>:<container-port>
```

### Host Port
```bash
apiVersion: v1
kind: Pod
metadata:
  name: example-pod
spec:
  containers:
  - name: my-container
    image: my-image
    ports:
    - containerPort: 80
      hostPort: 8080
```
