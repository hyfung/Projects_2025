# 6.2 Ansible Inventory

## Inventory File
- Denotes which node is monitored
- Use YAML for big tree
- Use INI for small tree

## Grouping and Parent-Child
INI
```ini
[parent_name:children]
webserver_1
webserver_2

[webserver_1]
webserver_1_1

[webserver_2]
webserver_2_1
```

YAML
```yaml
all:
    children:
        webservers:
        children:
            webserver_1:
                hosts:
                    server_1_1:
            webserver_2:
                hosts:
                    server_2_1:
```
