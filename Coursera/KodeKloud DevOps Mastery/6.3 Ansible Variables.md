# 6.3 Ansible Variables

## What is variable
- Store information for hostname, username, password
- Example: `ansible_connection=`, `ansible_host=`

## Storing Variable

### Variable file
```
my_var: 123
```

### YAML

Set `hosts` to the name of the variable file i.e. `web.yml`

`web.yml`
```yaml
http_port: 8081
snmp_port: 161-162
inter_ip_range: 192.168.0.0
```

`playbook.yaml`
```yaml
-
    name: Blah
    hosts: web
    tasks:
    - firewalld:
        port: '{{ http_port}}' /tcp
        permanent: true
        state: disabled
```

### INI

## Using Variable
- Reference as `{{ NAME }}` in inventory or playbook
- Jinja2 Templating

## Variable Types
- String
- Number: `int`, `float`
- Boolean: `true`, `false`, `0`, `1`, 0, 1
- List: A collection of value indexed by `[n]`
- Dictionary: KVP indexed by `{{ k.v }}`

## Registering Variable and Variable Precedence

### Short
1. Extra variable (Command line)
2. Playbook variable (Playbook file)
3. Host variable (`/etc/ansible/hosts`)
4. Group variable (Inventory file)
5. Role Default

### Long
Extra vars
Set facts
Include vars
Play vars
Host facts
Host vars
Group vars
Role default

## Capturing Output
- `register: result`
- `register` is used to capture output
- `result` is the variable name
- `var: result`
- `var` is used to expose the variable
- `result` is used to reference the variable
- Variable is available to a host for the rest of the playbook
- Scoped to a host

## Variable Scoping
- Host (Inventory)
- Play (Playbook)
- Global (Extra variable)

## Magic Variable
- Used to get information from other hosts
- `hostvars`
- `hostvars['host_name'].variable`
- `hostvars['host_name'].ansible_facts.variable`
- `groups['group_name']`
- `group_names`
- `inventory_hostname`
