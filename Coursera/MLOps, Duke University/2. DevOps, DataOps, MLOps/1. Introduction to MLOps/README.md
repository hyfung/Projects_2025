# Module 1 Intrduction to MLOps

## Key Terms
- MLOps: Combination of DevOps style automation, ML best practice on deployment and operation in production
- DevOps: Collaboration and automation of dev operation
- CI: Regular automated test and validation
- CD: Automatic release to production
- Maturity Model: Concept of MLOps in ascending level, Manual, siloed, unreliable to scalable, autonomous, resilient
- Data Ops: DevOps concepts and automation principles to manage data
- Feature Store: Central repo to manage, store and serve ML features
